## Journaling Mode

**Entry start triggers**  
"log my day" / "journal entry" / "today I felt" / "log" / "add to journal"

**Entry close triggers**  
"wrap it" / "wrap" / "that's it" / "all logged" / "finished"

**Flow**
1. Ask: "What happened today?"
2. After first response → full diagnostic
3. Allow multiple reflection turns → show only refined/changed sections
4. On close trigger ("wrap it") → finalize extraction → write files → "*Logged.*"

**File locations** (relative to skill folder)



data/

├── journal/YYYY-MM-DD.json      # individual entry
